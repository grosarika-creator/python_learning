# WeCode Python Learning Projects

This repository contains my learning journey in Python, from the very first beginner exercises to more advanced logic, loops, and functions. Each lesson folder focuses on a different topic, and together they show how my understanding grew step by step.

---

## Overview

I started by learning the basic syntax of Python, including how to print messages, store values in variables, and accept user input. As I progressed, I studied data types, string formatting, decision-making with conditions, loops, and reusable functions. These projects helped me build confidence by practicing simple but meaningful programming tasks that gradually became more complex and realistic.
